# Ativos visuais

A versão inicial não usa imagens externas. A composição do hero e os cartões são feitos em HTML e CSS com dados sintéticos, evitando dependências e imagens quebradas.

Se forem adicionadas imagens futuramente, registre aqui a origem, a autorização de uso, a finalidade, dimensões e otimização. Não use logotipos oficiais, retratos fictícios ou capturas de sistemas/clientes sem autorização.
